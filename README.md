# Les Vivée Clinic

Apresentação responsiva da clínica no Tatuapé, com React, TypeScript, Vite, Motion e Lenis. A marca foi vetorizada a partir da imagem de referência. O SVG champanhe trabalha sobre o fundo escuro do hero e a versão marrom sobre fundos claros.

```sh
npm ci
npm run dev
npm run check
npm run build
```

A Vercel usa o framework Vite, com saída em `dist/`. A prévia usa `noindex`. Ao conectar o domínio da Les Vivée, ajuste `VITE_LES_VIVEE_URL` para a nova origem HTTPS nas variáveis do projeto e refaça o deploy. Telefone, endereço e Instagram estão em `src/config/site.ts`.
